# lsd-detection-segmentation-severity

## Model limitations and retraining

The deployed checkpoint currently exposes the classes `healthy` and `infected`; it does not distinguish lumpy skin disease from foot-and-mouth disease. The current `train/masks` outputs are pseudo-masks generated by an existing model and must not be used as ground truth for a high-quality retraining run.

For reliable unseen-image performance, create verified annotations first:

- YOLO detection labels for every cow in each image, including crowded and multi-cow scenes.
- Pixel-accurate disease masks for every diseased region, with blank masks only for healthy images.
- A patient/image-level split into `train`, `valid_balanced`, and `test`, with no near-duplicate images across splits.

Then train the detector and segmentation model from those labels and evaluate precision, recall, F1, IoU, and per-class results on the held-out test split. Lowering the inference confidence helps recall but cannot replace missing labels.
